# Future Predictions

A static page of landmark inventions through history: when and where each was invented, its original purpose, whether it was adopted, lost and rediscovered, or repurposed, and what it ended up used for.

Live site: https://1brajesh.github.io/futurepredictions/

Plain HTML/CSS/JS in `index.html`, no build step. Last updated Oct 23, 2026.
